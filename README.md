# Family Time

Семейный учёт времени за компьютером: приложения, игры, сайты и YouTube. Необязательный веб-кабинет хранит историю для просмотра на компьютере и телефоне. Telegram остаётся дополнительным способом получать отчёты.

**Версия 0.2.0 — предварительная сборка для Windows 11 x64.** Основана на 0.1.2 с сохранением истории, родительского пароля и исправлений установщика. Добавлены веб-кабинет, привязка компьютера кодом и сохраняемая очередь синхронизации. Кабинет развёртывается отдельно на Vercel + Supabase: [настройка и ограничения](docs/CLOUD.md). Версия 0.1.2 остаётся доступна в предыдущем релизе.

## Установка

**[Релизы Windows](https://github.com/nezamerznet-source/controltime/releases)** — для кабинета выберите `FamilyTime-0.2.0-Setup.exe` в разделе **Assets**. Проверенный резервный выпуск: [v0.1.2](https://github.com/nezamerznet-source/controltime/releases/tag/v0.1.2).

1. Войдите в ту учётную запись Windows, в которой ребёнок пользуется компьютером.
2. Запустите `FamilyTime-0.2.0-Setup.exe`. Отдельный .NET или SDK для запуска не нужен. Можно установить поверх предыдущей версии с сохранением данных.
3. В первом окне задайте профиль и лимит, затем сохраните настройки.
4. При желании подключите [личный кабинет](docs/CLOUD.md), расширение Chrome/Edge и Telegram-бота по [инструкции](docs/QUICKSTART.md).

Внутри установленной программы находятся несколько файлов и расширение. Переносить один `FamilyTime.exe` отдельно от них нельзя. Установщик и программа пока без цифровой подписи издателя.

## Что умеет эта версия

- Веб-кабинет с входом по почте и паролю, адаптированный для телефона и компьютера: графики, приложения, сайты, история сеансов и состояние связи.
- Привязка компьютера одноразовым кодом, загрузка существующей истории и повторная отправка после восстановления интернета без двойного подсчёта.
- Учёт приложения на переднем плане; определение части известных игр и ручные правила категорий.
- Активный домен Chrome/Edge и сигнал воспроизведения YouTube через расширение.
- Разделение основного времени, предполагаемого простоя, блокировки, паузы и периодов без наблюдения.
- Фоновое видео отдельно от общего времени; расход лимита не удваивается.
- История на компьютере, просмотр периода, разбивка по приложениям и категориям.
- Дневной лимит: предварительное напоминание ребёнку и уведомление обоим при достижении. Учёт продолжается, блокировки нет.
- Отчёты после сеанса и завершённого дня; опционально — вечером и за завершённую неделю.
- Кнопки Telegram «Отчёт за сегодня», «Сколько осталось», команды `/today` и `/remaining`.
- Привязка конкретного родителя, повторные попытки доставки и сохранение очереди после перезапуска.
- Автозапуск, значок в области уведомлений, видимые действия «Пауза» и «Выход».
- Настройки остаются открытыми после сохранения. Telegram можно подключить позже.
- Родительский пароль: **Настройки → Защита**. Защищает настройки, категории, паузу и выход через приложение. Крестик только скрывает окно.
- Кнопки «?» с пояснениями: наведение мыши, нажатие или фокус с клавиатуры.
- Кнопка поддержки проекта, когда владелец добавит свой HTTPS-адрес в `branding.json`.

## Как устроен подсчёт

Пароль — защита внутри приложения, не системная служба. Диспетчер задач, отключение автозапуска средствами Windows и прямой доступ к файлам позволяют обойти её. Администратор Windows контролирует компьютер. Не оставляйте открытое окно родительских настроек ребёнку; сброса пароля через Telegram нет.

Один момент времени относится к одному приложению на переднем плане. При наличии расширения домен заменяет общую строку браузера. Состояние опрашивается примерно раз в секунду; это оценка с дискретностью опроса, а не запись действий пользователя.

Через 5 минут без ввода начинается предполагаемый простой. Подтверждённое воспроизведение YouTube на переднем плане позволяет продолжить учёт без мыши. XInput помогает учитывать поддерживаемые контроллеры. Чтение, просмотр других видеосервисов и неподдерживаемые контроллеры могут определяться неточно.

Отсутствующий сигнал расширения означает «браузер без детализации», а не ноль времени. История не восстанавливается за промежутки, когда приложение не работало. Часовой пояс фиксируется при первой настройке; его смена с пересчётом пока не реализована.

## Данные и Telegram

SQLite находится в `%LOCALAPPDATA%\FamilyTime\activity.db`. Хранятся интервалы, приложения, домены, категории, настройки и очередь отчётов. Подробные интервалы по умолчанию — 90 дней, дневные итоги — 365 дней. Токен защищён Windows DPAPI в этой учётной записи. Сама история не зашифрована приложением.

Нет скриншотов, записи клавиш, текста переписки, заголовков окон, названий роликов, полных URL, телеметрии разработчику или общего сервера. Бот получает только отчёты. Нажатие кнопки поддержки открывает внешнюю страницу без передачи статистики.

**Компьютер должен быть включён, приложение запущено, интернет доступен.** При выключенном компьютере немедленного ответа из Telegram не будет. Один токен бота используйте только для одного компьютера. При неопределённом результате отправки сеть может привести к повтору сообщения; стабильный номер внизу помогает распознать повтор.

## Сборка из исходников

Инструменты: .NET SDK 10.0.111 или более новый patch в ветке 10.0.1xx (в CI 10.0.112), Python 3.11+, Node.js 24, NSIS 3.09. Готовая поставка включает .NET Runtime 10.0.12.

Из корня проекта:

```powershell
python packaging/build.py
```

Скрипт проверяет ядро и расширение, публикует приложение и native host для `win-x64`, собирает установщик, архив расширения, архив исходников и `SHA256SUMS.txt` в `artifacts/`. При необходимости задайте пути через `FAMILYTIME_DOTNET`, `FAMILYTIME_NODE`, `FAMILYTIME_MAKENSIS`.

Отдельные проверки:

```powershell
dotnet run --project tests/FamilyTime.Tests/FamilyTime.Tests.csproj -c Release
node --test extension/tests/state.test.js
```

Решение: `FamilyTime.slnx`. Внешних NuGet-пакетов бизнес-логики нет; на Windows используется системная `winsqlite3.dll`, в тестах Linux — `libsqlite3.so.0`.
