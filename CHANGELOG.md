# 0.1.3 — Отчёт перед выключением компьютера

- В разделе «Отчёты и данные» добавлен переключатель с подсказкой; по умолчанию включён, требуется Telegram.
- Перед штатным выключением, перезагрузкой или выходом из Windows сохраняется дневной итог и выполняется попытка отправки с сетевым сроком до 3 секунд.
- Отчёт получает приоритет перед накопленной очередью. При неудаче исходный срез остаётся в базе до следующего запуска; конкурентные отправители не дублируют сообщение.
- Сообщение описывает начало завершения работы, не обещает подтверждение отключения питания. При внезапном обесточивании отправка невозможна.
- Проверки сохранения настройки, содержимого отчёта, повторных событий, очереди после перезапуска, тайм-аута и ошибок Telegram; WPF-сценарий вызывает обработчик завершения с тестовым API без реального выключения Windows.

# 0.1.2 — Настройки и родительская защита

- Явная UTF-8 кодировка исходников NSIS при сборке: русский текст установщика больше не зависит от системной локали.
- Настройки остаются открытыми после сохранения; повторное открытие из ярлыка и трея восстанавливает главное окно.
- Исправлено подтверждённое падение при появлении статистики: привязка ProgressBar к неизменяемому Percent явно установлена в OneWay.
- Родительский пароль защищает настройки, категории, паузу и полный выход. PBKDF2-SHA256 с индивидуальной солью, ограничение повторных попыток.
- Защищены штатные команды завершения и удаления; это не защита от диспетчера задач, прямого доступа к файлам или администратора.
- Пояснения с кнопкой «?» у разделов и параметров. Telegram можно подключить позже.
- Проверки Windows проходят полный сценарий первого сохранения, учёта, скрытия и повторного открытия, а также сохранения пароля. Скриншоты интерфейса сохраняются для проверки.

# 0.1.1 — Startup fix

- Include the main window icon as a WPF resource (the executable icon alone is insufficient).
- Display the underlying startup error and save a local diagnostic log; fall back to the temporary folder if the data folder is unavailable.
- Before packaging on Windows, initialize the database and load both WPF windows using an isolated temporary profile. Abort packaging on failure or timeout.
- Existing databases and family settings are preserved.
