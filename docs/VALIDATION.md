# Проверка сборки 0.1.0

Дата подготовки: 28 сентября 2026.

## Выполнено в среде Linux

- 27 автоматических проверок C# ядра: все пройдены.
- 4 автоматические проверки логики расширения Node.js: все пройдены.
- Компиляция WPF-приложения для Windows x64: без ошибок и предупреждений.
- Публикация self-contained приложения и native host для Windows x64 с .NET Runtime 10.0.12.
- Установщик NSIS, архивы и контрольные суммы собраны скриптом `packaging/build.py`.
- Проверены Windows PE-заголовки установщика и обоих приложений, целостность ZIP-архивов и отсутствие `bin`, `obj`, баз и символов отладки в архиве исходников.

Ключевые сценарии тестов: разделение foreground-интервалов, idle и видео, отсутствие двойного учёта фона, lock/sleep, пропуски и откат часов, полночь и DST, перезапуск SQLite, сохранение расхода/порогов, дедупликация, авторизация Telegram, срок привязки, отложенный запрос, транзакционный ответ и очередь, хранение/удаление истории.

C#-проверки используют настоящую SQLite. Telegram заменён тестовым интерфейсом, реальные сообщения не отправлялись. Проверки расширения выполняют чистую логику состояния вкладок, а не Chrome API. Тесты не добавляли искусственные данные в пользовательскую базу.

## Требует Windows и аккаунта владельца

В этой среде нет рабочего стола Windows, установленного браузера с расширением и токена Telegram пользователя. Поэтому **не подтверждены ручным запуском**:

- отображение и работа WPF-интерфейса;
- первый запуск/обновление/удаление установщика;
- реальные Win32/XInput-события и блокировка/сон;
- native messaging Chrome/Edge и фоновое воспроизведение YouTube;
- DPAPI, автозапуск, видимость локального баннера;
- настоящая доставка Telegram и поведение при сетевых сбоях;
- долгий игровой сеанс, расход памяти, CPU и диска.

Пошаговый список для такой проверки — `WINDOWS-ACCEPTANCE.md`. GitHub Actions подготовлен, но не запускался в аккаунте владельца. EXE не подписан сертификатом издателя. Эта версия предназначена для первой проверки, а не заявлена как проверенный публичный релиз.

## Инструменты

Локальный SDK: 10.0.111; runtime пакетов Windows: 10.0.12; NSIS: 3.09. WPF перекрёстно компилируется с `EnableWindowsTargeting`. Для SQLite на Windows используется системная winsqlite3, в Linux-тестах — libsqlite3. Процесс сборки и его зависимости описаны в README.
