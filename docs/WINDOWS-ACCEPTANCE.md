# Приёмка на Windows 11 x64

Статус каждого пункта до ручного запуска: **не проверено**. Запишите фактический результат и версии ОС/браузера рядом с пунктом. Не прикладывайте токены и личную историю к публичному issue.

| Проверка | Ожидаемый результат |
|---|---|
| Чистая установка без .NET SDK | Первый запуск; сбор до сохранения настроек не идёт |
| Вход в Windows и закрытие главного окна | Автозапуск после настройки; tray и учёт продолжают работать |
| Игра 2 мин → редактор 1 мин | Общий итог около 3 мин, приложения не пересекаются |
| Chrome: сайт A → сайт B | Время относится к активному домену; суммарная строка браузера его не удваивает |
| Закрыть браузер и продолжить игру | Учёт игры продолжается независимо от расширения |
| Отключить расширение | Появляется браузер без детализации, время не исчезает |
| YouTube без мыши, затем пауза | Подтверждённое активное видео учитывается; на паузе после idle-порога не учитывается |
| Фоновый YouTube + игра | Основной итог равен игре; видео отображается отдельно |
| Минимизировать браузер | Активная вкладка не подменяет приложение на переднем плане |
| Несколько вкладок YouTube | Фон хранится как объединённое время, без умножения по вкладкам |
| Нет ввода 6 мин, idle=5 | Последняя минута примерно соответствует предполагаемому простою |
| XInput-контроллер в игре | Поддерживаемый ввод обновляет активность; проверить удержание и движение стиков |
| Win+L, сон, пробуждение | Заблокированный/спящий интервал не увеличивает расход |
| Полночь во время игры | Время делится между двумя днями, лимит нового дня отдельный |
| Завершение/перезапуск приложения | История и расход сохраняются; пропуск не превращается в игровое время |
| Лимит 3 мин, предупреждение 1 мин | Одно предупреждение ребёнку, один порог ребёнку и родителю |
| Перезапуск после достигнутого лимита | Расход сохранён, повторное уведомление того же события не создаётся |
| Уменьшить лимит ниже расхода | Один новый порог с пояснением об изменении лимита |
| Повторно сохранить те же настройки | Нового порога нет |
| Нет интернета при достижении лимита | Локальный индикатор обновлён, Telegram остаётся в очереди; после восстановления доставляется |
| Оба Telegram-запроса | Период, итог и остаток совпадают с локальным экраном на момент ответа |
| Запрос другого аккаунта/группы | Нет отчёта и утечки статистики |
| Выключить ПК, запросить, включить | Нет немедленного ответа; обработанный поздний запрос явно подписан |
| Заблокировать бота, затем восстановить | Видна ошибка очереди; после повтора доставка возобновляется |
| Режим «Не беспокоить» и полноэкранная игра | Баннер может быть скрыт; остаток в UI остаётся достоверным |
| Изменить категорию | Новые интервалы получают правило; прежняя история не перекрашивается |
| Отчёт сеанса и дневной итог | Оба имеют понятный период; расход полного дня не заменяется суммой одного сеанса |
| Обновление в прежнюю папку | Приложение закрывается корректно, после запуска история и бот сохранены |
| Удаление с сохранением/очисткой | Автозапуск и регистрация удалены; данные только по выбору пользователя |
| 100/125/150/200% DPI | Читаемые поля, доступные кнопки, отсутствие обрезки основных значений |
| Сеанс 2–4 часа | Нет заметного влияния на игры, утечки памяти или роста базы каждую секунду при неизменном состоянии |

Точность оценивать с допуском опроса примерно 1–2 секунды на переключение. Округлённые минуты в строках отчёта могут отличаться от суммы отображённых минут; внутри хранятся секунды.
