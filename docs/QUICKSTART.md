# Первый запуск Family Time 0.1.0

## 1. Установите приложение

ОС для этой сборки — Windows 11 x64. Запустите `FamilyTime-0.1.0-Setup.exe` в учётной записи ребёнка, без запуска от имени другого администратора. Установка выполняется для текущего пользователя; отдельная установка .NET не требуется.

Путь по умолчанию: `%LOCALAPPDATA%\Programs\FamilyTime`. В меню «Пуск» появится Family Time. Задайте понятное имя профиля и лимит, например 120 минут. Нажмите «Сохранить и начать учёт».

Значок часов в области уведомлений открывает статистику. Закрытие окна сохраняет работу приложения; полное завершение — пункт «Выход» в меню значка.

Это предварительная сборка без подписи издателя. Windows может показать сообщение о неизвестном издателе. Перед запуском проверьте происхождение файла и SHA-256 по приложенному `SHA256SUMS.txt`; отключать защиту Windows не требуется.

## 2. Добавьте расширение браузера

В Family Time откройте **Настройки → Браузер → Открыть папку расширения**. Затем:

1. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `%LOCALAPPDATA%\Programs\FamilyTime\extension` или папку `extension` из выбранного при установке каталога.
5. Откройте обычный сайт и проверьте «Расширение подключено» в настройках программы.

Ожидаемый ID расширения: `gejjgahgdjgflfpbkoocabdmmjeekihf`. Не меняйте поле `key` в манифесте: оно связывает расширение с установленным компонентом.

Браузер попросит разрешение на сведения о вкладках и связь с локальной программой. Из адреса в приложение передаётся только домен. Для YouTube дополнительно передаётся признак воспроизведения. Инкогнито не детализируется. Для первого теста используйте один обычный профиль браузера.

Если связи нет, нажмите **«Восстановить связь с браузером»**, перезагрузите расширение на странице расширений и убедитесь, что Family Time работает. Если программа обновлена, закройте браузеры перед установкой новой версии.

## 3. Создайте Telegram-бота

1. С аккаунта родителя откройте официальный [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username бота.
3. Скопируйте токен в **Family Time → Настройки → Telegram**.
4. Нажмите «Проверить токен и привязать родителя».
5. Программа покажет ссылку. Откройте её именно с аккаунта родителя и нажмите **START / Запустить**. Ссылка действует 10 минут.
6. Дождитесь сообщения о подключении и нажмите «Отчёт за сегодня».

Не публикуйте токен, ссылку привязки и базу данных на GitHub или в сообщении об ошибке. Для каждого компьютера создайте отдельного бота. Если токен уже используют другой сервис или webhook, программа покажет конфликт; чужие настройки она не удаляет.

В боте доступны:

| Кнопка или команда | Что получите |
|---|---|
| Отчёт за сегодня / `/today` | Учтённое время на момент ответа, приложения, сайты и категории |
| Сколько осталось / `/remaining` | Остаток дневного лимита или превышение |
| `/help` | Подсказка по командам |

## 4. Проверьте лимит

В настройках задайте небольшой тестовый лимит, например 3 минуты, и предварительное предупреждение 1 минуту. Пользуйтесь компьютером до достижения порога. Проверьте сообщение родителю и индикатор остатка в окне. После теста установите обычный лимит.

Лимит один на всё основное время; учёба тоже входит. Повторный запуск не обнуляет расход. Снижение лимита ниже уже учтённого времени вызывает уведомление об изменении лимита. Новое значение может дать новое уведомление; повторное сохранение того же значения не создаёт новую редакцию.

Windows может скрыть локальный баннер в игре или режиме «Не беспокоить». Для отдельной проверки есть кнопка «Проверить уведомление Windows». Автоматической блокировки компьютера в этой версии нет.

## 5. Автоматические отчёты

По умолчанию включены отчёт после перерыва 15 минут и итог завершённого дня. Если в полночь компьютер был выключен, итог готовится после следующего запуска. Вечерний срез и недельный итог включаются отдельно. Сеанс, который не успел отправиться перед выключением, обрабатывается при следующем запуске.

Без интернета учёт остаётся локальным, готовые сообщения ждут в очереди. Период отчёта и время его формирования указаны в сообщении. Если запрос из Telegram дождался включения компьютера, он показывает статистику на момент обработки.

## Обновление, перенос и удаление

Перед обновлением закройте Chrome и Edge. Запустите новый установщик в той же учётной записи и выберите прежний каталог. История хранится отдельно от программы.

Для резервной копии завершите Family Time через значок и скопируйте `%LOCALAPPDATA%\FamilyTime`. Токен DPAPI привязан к учётной записи/Windows: при переносе базы на другой компьютер подключите Telegram заново. Не отправляйте эту папку публично.

Удаление: **Параметры Windows → Приложения → Установленные приложения → Family Time → Удалить**. Удаление данных спрашивается отдельно; по умолчанию они сохраняются. Расширение удалите на странице расширений браузера.

Если приложение не запускается, сохраните резервную копию папки данных и проверьте свободное место. Не удаляйте единственную копию базы ради диагностики. Для сообщения об ошибке достаточно версии Windows/браузера, версии Family Time и последовательности действий без личной статистики.
