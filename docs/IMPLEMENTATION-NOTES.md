# Решения первой сборки

Исходное ТЗ сохранено в `specification.md`. Это ориентир проекта; ниже явно перечислены принятые решения и оставшаяся работа.

| Область | В 0.1.0 |
|---|---|
| Рабочее имя | Family Time; можно переименовать перед публичным выпуском |
| ОС | Windows 11 x64; один пользователь и компьютер |
| Интерфейс | WPF, светлый интерфейс, статистика/история/категории/настройки, tray |
| Лимит | 120 минут по умолчанию, мягкие уведомления, изменение на компьютере |
| Простой и сеанс | 5 и 15 минут, оба значения настраиваются |
| Браузеры | Chrome/Edge, вручную установленное расширение, один обычный профиль для приёмки |
| YouTube | Домен и воспроизведение; ролики, история просмотров и названия не собираются |
| Telegram | Собственный бот семьи, long polling, привязка chat_id + user_id |
| Уведомления | NotifyIcon Windows; собственного оверлея поверх игр нет |
| PIN | Не добавлен; параметры доступны пользователю компьютера |
| Категории | Предустановленный небольшой список игр + ручные правила для будущих интервалов |
| Часовой пояс | Фиксирован при первой настройке; смена с историческим пересчётом пока отсутствует |
| Исторические лимиты | Редакции сохраняются в базе; в старых отчётах текущий лимит не подставляется вместо исторического |
| Донаты | Настраиваемая внешняя HTTPS-страница, кнопки скрыты до указания адреса |
| Лицензия и GitHub | Файлы репозитория и сборочный workflow готовы; лицензия не выбрана, публикации не было |

## Что ещё нужно до публичного выпуска

- Пройти сценарии Windows с настоящим foreground, XInput, lock/sleep, браузером, баннерами и Telegram. Снять реальные скриншоты интерфейса после запуска.
- Проверить отображение WPF на 100/125/150/200% DPI, тёмную тему ОС и системные контрастные режимы; при необходимости поправить интерфейс.
- Измерить CPU, память и запись на диск за длительный сеанс. Пока интервалы фиксируются каждую секунду, хотя соседние записи объединяются.
- Выбрать лицензию, адрес репозитория и адрес страницы поддержки. Точные платёжные способы определяет владелец.
- Решить вопрос подписи EXE и распространения расширения через Chrome Web Store / Edge Add-ons. У магазина может быть другой ID, его нужно согласовать с native host.
- Проверить пользовательскую настройку, обновление и удаление установщика на чистой Windows, включая закрытый и работающий браузер.

## Практические ограничения

Без сервера приложение не отвечает при выключенном ПК. Нельзя гарантировать обнаружение обхода учёта, непрерывность наблюдения после принудительного завершения, просмотр человеком реально воспроизводимого видео, точность неизвестных игр/контроллеров или показ баннера поверх игры. Уведомления и отчёты отражают измеренное время.

Просмотр Netflix, локального плеера и других источников без ввода после idle-порога может считаться простоем. Расширение не охватывает системные страницы, инкогнито, встроенные браузеры приложений и Firefox. Несколько профилей с неоднозначным фокусом дают браузер без детализации.

Установщик собран, однако сборка Linux сама по себе не подтверждает, что интерфейс и интеграции правильно работают в Windows. Полный статус проверок находится в `VALIDATION.md`.
